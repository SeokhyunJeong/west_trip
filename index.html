일정은 이 기기·브라우저에 저장됩니다. 다른 기기로 옮길 때는 백업 파일을 내보낸 뒤 불러오세요. 배포된 페이지에서도 같은 방식으로 사용할 수 있습니다.

백업과 복원

이 공개 페이지는 모든 방문자가 같은 일정을 수정하며, 공용 저장소에 최근 10개 변경 이력을 보관합니다. 브라우저 데이터 삭제나 다른 주소로 이동하기 전에는 파일로 저장해 주세요. HTML 백업에는 일정과 편집 화면이 함께 들어갑니다.

Google 하루 전체 지도 연결

Google 장소 지도는 바로 사용할 수 있어요. 선택한 날짜의 모든 방문 장소와 경로를 한 지도에 표시하려면 Google Maps Embed API 키를 연결해 주세요.

Google Cloud에서 Maps Embed API를 활성화하고, 키의 웹사이트 제한에 실제 배포 주소 또는 http://127.0.0.1:4173/* 를 등록하세요. API 제한은 Maps Embed API로 설정하세요. 키는 이 브라우저에만 저장하며 일정 백업에 포함하지 않습니다.
